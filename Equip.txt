# Project Core Objective
To deploy a highly resilient, local-first Smart Home and Network Attached Storage (NAS) ecosystem. This system integrates Home Assistant for automation control, Frigate NVR for AI-powered video surveillance, Cloud storage for my Daughter who's in college, OpenShot video editing for my son's baseball efforts, and secure data storage using the foundation defined in the repository: https://github.com/jharvey/HA-setup.git.
